history Crear Nueva Versión de Arrendamiento

security Política de Continuidad y Trazabilidad

Por trazabilidad y control del cultivo, cuando se crea una nueva versión de un arrendamiento, no se permite cambiar el arrendatario. Esto garantiza la continuidad del seguimiento del cultivo, ya que el historial, los datos de monitoreo y los procesos asociados pertenecen al arrendatario original.

Beneficios para el propietario:

  • Evita confusión o pérdida de datos entre arrendatarios
  • Protege la integridad del seguimiento técnico del cultivo
  • Da claridad en auditorías, reportes y certificaciones

¿Necesita asignar un nuevo arrendatario?
Debe crear un arrendamiento completamente nuevo, independiente del anterior. Así se inicia una nueva trazabilidad con el nuevo responsable.
