¿Por qué crear un nuevo arrendamiento?

Cuando se requiere cambiar el arrendatario o iniciar un nuevo ciclo de arrendamiento con parcelas diferentes, debe registrarse un nuevo arrendamiento independiente.

Esto asegura que cada arrendatario tenga su propio historial, datos de seguimiento y responsabilidades claras.

🔒 Política de trazabilidad y responsabilidad

Por integridad operativa y trazabilidad del cultivo:

"Cada arrendamiento está vinculado de forma única a un arrendatario. No se comparte historial ni monitoreo entre arrendamientos distintos."

📌 ¿Qué debe hacer si desea continuar con el mismo arrendatario?

Si las condiciones cambian (fechas o valor), pero el arrendatario sigue siendo el mismo, puede optar por crear una nueva versión del arrendamiento existente desde la vista principal.

👉 Use el botón "Crear nueva versión" en la tabla de arrendamientos para conservar el historial.
